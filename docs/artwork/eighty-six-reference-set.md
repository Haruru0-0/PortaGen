# Eighty-Six reference artwork set

The author supplied eleven Shin and Lena pictures and requested the same art style for the whole set. Each source is edited individually using clean TV-anime linework and restrained cel shading, with matched cobalt underwater backgrounds and interface space. Faces, expressions, outfits, and poses are preservation targets; cropped body/clothing regions are generated where needed. These edits are generated fan art, not official anime artwork.

Full-resolution PNGs and optimized WebP copies are saved under `public/artwork/eighty-six/reference-set/` after generation. No mockup or app screen is assigned a new image automatically.

Completed on 2026-11-08: all eleven outputs were visually reviewed and saved at 1586 × 992 pixels. The directory contains eleven PNGs, eleven WebP display copies, a source/prompt manifest, and an artwork index. A ZIP copy is saved in this chat's visualization directory as `eighty-six-reference-artwork.zip`.
